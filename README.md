# Heart Mortality Prediction

This project uses machine learning techniques to predict heart mortality risk based on patient health data.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## Files
- PHFMR.ipynb : Model development and analysis
- heart_failure_dataset_realistic.csv : Dataset

## Objective
To predict heart mortality risk and assist in healthcare decision-making.
